Cyber Awareness Centre

Clear, practical guidance for people and teams.

Phishing

Fraudulent messages that trick people into sharing credentials or running malware.

  • Check the sender address, not the display name
  • Never approve unexpected MFA prompts
  • Report suspicious mail instead of deleting it

Ransomware

Malware that encrypts data and demands payment.

  • Keep offline, tested backups
  • Patch internet-facing systems quickly
  • Limit admin rights

Malware

Software built to steal, spy or disrupt.

  • Install software only from trusted sources
  • Keep endpoint protection active
  • Remove unused applications

Data protection

Keeping personal and business data confidential and available.

  • Collect only the data you need
  • Encrypt devices and backups
  • Review who has access regularly

Security awareness

Helping every employee make safer decisions.

  • Short, regular training beats annual sessions
  • Run phishing simulations with consent
  • Make reporting easy and blame-free
